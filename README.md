# Agentic Finance App

**Purpose:**  
- Fetch & analyze stock data from Yahoo Finance and Alpha Vantage  
- Provide proactive monitoring, opportunity detection, and rebalancing suggestions  
- Expose an interactive Streamlit UI

**Setup:**  
1. `python3 -m venv venv && source venv/bin/activate`  
2. `pip install -r requirements.txt`  
3. Fill in `config.py` with your Alpha Vantage API key  
4. `python main.py` to verify imports
